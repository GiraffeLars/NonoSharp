# NonoSharp
[![NuGet Version](https://img.shields.io/nuget/vpre/NonoSharp?label=NuGet)](https://www.nuget.org/packages/NonoSharp/)

Welcome to the documentation for the NonoSharp API! Here you will find a small introduction and example
code, together with the documentation of the package.

## Getting started
To get started, navigate to [Introduction](docs/introduction.md) or immediately get started
by installing the package by running the command below and browsing the 
[API documentation](xref:NonoSharp).
```shell
dotnet package add NonoSharp
```
