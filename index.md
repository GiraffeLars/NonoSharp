# NonoSharp
[![NuGet Version](https://img.shields.io/nuget/vpre/NonoSharp?label=NuGet)](https://www.nuget.org/packages/NonoSharp/)

Welcome to the documentation for the NonoSharp API! NonoSharp is a library for C\# allowing users to easily create, solve and save their own, or random, [Nonogram](https://en.wikipedia.org/wiki/Nonogram) puzzles. On this site you will find a small introduction to NonoSharp together with example
code, and documentation for the API.

## Getting started
To get started, navigate to [Introduction](docs/introduction.md) or immediately get started
with installing the package by running the command below and browsing the 
[API documentation](xref:NonoSharp).
```shell
dotnet package add NonoSharp
```
